# Issue tracker: GitHub

Issues de NLP vivem em `rodcordeiro/banky-nlp`. Use `gh issue` neste checkout. Toda issue planejada deve integrar o [Banky Project #11](https://github.com/users/rodcordeiro/projects/11), com `Status`, `Priority` e `Size` revisados.

PRs não são superfície de entrada para triagem. Dependências com API, app ou MCP devem usar issues próprias e links recíprocos.

Quando uma skill disser “publique no issue tracker”, crie uma GitHub issue neste repositório e confirme sua associação ao Project #11. Para buscar um ticket, use `gh issue view <numero> --comments`.
